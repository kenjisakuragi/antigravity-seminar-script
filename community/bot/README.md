# AI一次対応bot（らくらくAIキャンパス）

`@AIサポート` とメンション、または「質問ひろば」チャンネルで、講座内容に沿ってやさしく自動回答します。
**今後の変更に強い設計**：回答の中身は `knowledge/*.md` を編集するだけ（コード不要）。運用は `config.py` の一箇所。

---

## セットアップ（初回のみ）

### 1. Intent を2つ ON にする（必須）
Developer Portal → あなたのApp → **Bot** → 下の **Privileged Gateway Intents** →

- **MESSAGE CONTENT INTENT** … OFFだと質問の文章を読めません
- **SERVER MEMBERS INTENT** … OFFだと「今週の栞」の“2週サイレント”を見られません

両方ONにして保存。

### 2. APIキー（もう設定済み）
**ChatGPT（OpenAI）を使います。** キーはリポジトリ直下の `.env` の `OPENAI_API_KEY` を
そのまま読むので、**追加の作業はありません**。

### 3. パッケージ（インストール済み）
```powershell
$py = 'C:\Users\yanagi\AppData\Local\Programs\Python\Python312\python.exe'
& $py -m pip install discord.py openai python-dotenv
```

### 4. 起動
```powershell
& $py community\bot\ai_support_bot.py
```
→ 「AIサポート稼働」と出れば成功。Discordで「質問ひろば」に書くか、Botに @メンション してテスト。

## 使い方・運用

### 回答の中身を変える（＝知識ベースの編集）
`community/bot/knowledge/` の中の markdown を編集・追加するだけ。
- `00_about.md` … キャンパスの全体像
- `faq.md` … よくある質問（ここに Q/A を足すのが一番かんたん）
- `prompts.md` … 「こう話しかけるといい」テンプレ集
- `bonus.md` … 特典4つ・今週の栞・返金条件（**進み具合や人数は答えない**と書いてある）
- 新しいファイル（例 `payments.md`）を足してもOK。自動で読み込まれます。

編集後、Discordで **`!reload`**（運営・認定講師のみ）と打てば、**再起動なしで反映**。

### 動き・安全
- 健康／お金／法律の重い相談 → **助言せず・肯定も否定もせず、やわらかく流す**（説教くさく専門家へ突き放さない）（`config.SAFETY`）
- 答えきれない質問 → 「講師が対応します」の文（`config.ESCALATION`）を返す
- bot自身は収入・成果を約束しない。ただし個人情報や収入保証について、こちらから明示的な注意・警告はしない（自然に振る舞う）

### 設定を変える（`config.py`）
- `AUTO_REPLY_CHANNELS` … 自動応答するチャンネル名
- `MODEL` … 既定 `gpt-5.4-mini`（安い）。もっと安く `gpt-5.4-nano` ／ 賢く `gpt-5.4`
- `REASONING` … 既定 `low`。一次対応で長考は要らない（遅く・高くなるだけ）
- `PERSONA` / `SAFETY` / `ESCALATION` / `FOOTER` … トーン・安全・文言
- `ADMIN_ROLES` … `!reload` を使えるロール

## 「今週の栞」の運用（特典③）

`shiori.py` が担当。ai_support_bot と**同じプロセス**で動くので、起動は1つでよい。

| いつ | 何を |
|---|---|
| 毎週月曜 朝7:00 | 📖今週の栞 に「今週の一行、どうぞ」を投稿（文面は3種を持ち回り） |
| 誰かが書いたとき | **必ず1件**、短くあたたかい返事（長かったら定型に落とす） |
| 月曜の投稿と同時 | 2週つづけて書いていない方に、そっとDMを1通 |

### 絶対に守ること（コードを変える前に読む）

- **書いていない人に、公開の場で触れない**（名指しも、ほのめかしも）
- **人数を発表しない。**「今週は◯人が書きました」は、書かなかった人への減点になる
- 公開の投稿に**週番号を出さない**。入会日が人ごとに違うので、遅く入った人が置いていかれる
- DMは**1回だけ**。返事がなくても二度追わない（同じ人へは最短6週あける）
- 「お休みでも大丈夫」を、毎回どこかに置く

### 記録ファイル

`community/bot/_shiori_state.json` に、最後に書いた週・最後にDMした週を持つ。
**これが消えると「二度追い」が起きる**ので、バックアップの対象に入れること。

### 部屋を作る

```powershell
& $py community\_make_shiori_channel.py --plan   # 何をするか見るだけ
& $py community\_make_shiori_channel.py          # 作る
```
チャンネル名を変えるときは、`shiori.py` の `CHANNEL_KEYS` と、
ステップメール本文（`_load_shiori.py` の `CH`）も合わせること。

## 「おはようチャレンジ」の運用

`morning.py` が担当。これも同じプロセスで動く。

| いつ | 何を |
|---|---|
| 毎朝 6:30 | あいさつ＋その日のひと言を投稿 |
| 誰かが書いたとき | **全員にスタンプ**。言葉で返すのは「その日の最初の1人」と「20字以上書いた人」だけ |

### なぜ全員に言葉を返さないか

30人が「おはようございます」と書く部屋でbotが30回返事をすると、**人の会話が埋まる**。
受講生どうしが「〇〇さんおはよう」と言い合う余白が消える。
スタンプなら「見てるよ」は伝わるし、じゃまにならない。**ここはbotが主役の部屋ではない。**

### ひと言が毎日同じにならないように

日付だけ渡すと、AIは毎日「今日も暑いですね」を書く（実際そうなった）。
`TOPICS`（台所・眠り・窓の外…14個）を日付順に回し、直近7日ぶんの文面も渡して避けさせている。

### 言わせないこと

- 「◯日連続ですね」「久しぶりですね」— **数えていることを見せない**
- 「必ず」「引き寄せ」「叶いま」を含む文は、機械的にはじいて定型文に落とす

設定は `morning.py` の上部（時刻・スタンプ・返事の字数しきい値）。

## 24時間動かすには（ホスティング）
このスクリプトは**動かし続ける場所**が必要です（PCを閉じると止まります）。
- 常時稼働のサーバー（Railway / Render / VPS 等）に置くと24時間応答します。
- まずは手元のPCで動作確認 → 良ければホスティングへ、の順がおすすめ。

## 費用の目安
- 知識ベース（約5,300文字）は毎回同じ文面なので、OpenAI側が自動でキャッシュします。設定は不要。
- 費用は主に「回答の長さ」で決まります。`gpt-5.4-mini` は十分に安く、この規模なら実用上ほぼ気になりません。
- さらに下げたいときは `MODEL = "gpt-5.4-nano"`。ただしトーンは少し素っ気なくなります。

## このPC特有の話（TLS）
このPCは通信の中身を覗く構成のため、素のままだとOpenAIへの接続が証明書エラーで落ちます。
`ai_support_bot.py` は起動時に `interviews/_win_roots.pem`（Windowsの証明書ストアから
書き出した束）を `SSL_CERT_FILE` に入れて回避します。**検証は切っていません。**
別のPCやサーバーに載せるときは、このファイルが無くても普通に動きます。

## セキュリティ
- `.env`（トークン・APIキー）はGit管理外（設定済み）。人に見せない。
- Discordトークンは、平文で共有したら**リセット**を。
