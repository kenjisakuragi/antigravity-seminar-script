## ⚠️ この調査を頼む前に、知っておいていただきたいこと

| | 私の理解 |
|---|---|
| ChatGPTとAPIの財布 | **別々**です。ChatGPTをいくら払っても、APIの請求は減りません |
| Codex CLI | ChatGPTログインで動きます。**これは公式の使い方**です（画像生成で、すでにそうしています） |

| 規約 | 個人の対話利用が前提。**第三者へのサービスの裏側**に使うのは、危ういところです |
