# AIニュースの日次投稿｜設計案

> 2026-09-11 ／ AIさくらぎに足す機能
> 投稿先：**#aiニュース**（すでにあるチャンネル）

---

## 0. いちばん大事な決めごと

### ⚠️ AIに「今日のニュースを探して」と頼まない

これをやると、**存在しないニュースを、それらしく書きます。**
AIは、自分が最近の出来事を知らないことを知りません。日付も、社名も、金額も、平気で作ります。

受講生は40〜60代で、**書いてあることを信じてくださる方**です。
嘘のニュースを1回出したら、AIさくらぎ全体の信用が終わります。

**ですので、こうします。**

```
ニュースを見つけるのは … RSS（各メディアの配信）＝ 機械。嘘をつけない
やさしく書き直すのは  … AI              ＝ 文章だけ担当
```

**AIには、RSSで実際に取れた記事しか渡しません。** そして
「渡した記事に**書いていないことは、一文字も書かない**」と指示します。
出典のURLも、RSSから取った実物をそのまま貼ります。AIには作らせません。

## 1. 全体の流れ

```
① 集める（RSS・8媒体）        毎朝 7:45
        ↓  100〜200本
② 機械でふるいにかける         AIに渡す前に、ここで9割落とす
        ↓  15〜25本
③ AIが3本選び、やさしく書く    1日1回のAPI呼び出し
        ↓
④ 投稿する（または桜木さんへDM） 8:00
```

## 2. どこから集めるか（RSS・動作確認済み）

2026-09-11 に、実際につないで確かめました。

| 媒体 | 件数 | URL |
|---|---|---|
| **ITmedia AI＋** | 20 | `https://rss.itmedia.co.jp/rss/2.0/aiplus.xml` |
| **AI Watch（Impress）** | 30 | `https://ai.watch.impress.co.jp/data/rss/1.0/aiw/feed.rdf` |
| ITmedia NEWS | 50 | `https://rss.itmedia.co.jp/rss/2.0/news_bursts.xml` |
| ASCII.jp | 30 | `https://ascii.jp/rss.xml` |
| CNET Japan | 30 | `https://japan.cnet.com/rss/index.rdf` |
| Impress Watch | 20 | `https://www.watch.impress.co.jp/data/rss/1.0/ipw/feed.rdf` |
| ギズモード・ジャパン | 20 | `https://www.gizmodo.jp/index.xml` |
| PR TIMES | 200 | `https://prtimes.jp/index.rdf` |

**上の2つがAI専門**です。ここだけで足りる日がほとんどです。
残りは「AIの話が一般ニュースになった日」を拾うための保険です。

⚠️ 形式が2種類あります（RSS 2.0 と RDF）。**読み方が違います。**
　 RDF側は名前空間 `http://purl.org/rss/1.0/` を指定しないと、0件に見えます（実際にそうなりました）。

⚠️ PR TIMESは200本と多く、**企業の宣伝が大半**です。AI専門媒体が取れた日は、使いません。

## 3. 機械でふるいにかける（AIに渡す前）

**ここで9割落とします。** AIに200本渡すと、高くなるうえ、選び方も雑になります。

| 順 | 何をするか |
|---|---|
| 1 | **36時間以内**の記事だけ残す |
| 2 | **同じ記事を消す**（URLを正規化して重複除去。同じ話を複数媒体が書く） |
| 3 | **前に出した記事を消す**（過去30日ぶんのURLを覚えておく） |
| 4 | **AIに関係ない記事を消す**（AI専門媒体以外は、下のことばを含むものだけ残す） |
| 5 | それでも多ければ、**媒体ごとに上位5本**まで |

**残すことば**
```
AI／生成AI／ChatGPT／Gemini／Claude／Copilot／画像生成／動画生成／音声合成／
OpenAI／Anthropic／Google／文字起こし／自動化／エージェント
```

**落とすことば**（受講生には関係が薄い）
```
株価／時価総額／資金調達／シリーズA／ラウンド／半導体／データセンター／
決算／IPO／買収／論文／ベンチマーク／パラメータ／API仕様／SDK
```

⚠️ **落とすことばのほうが大事です。** 資金調達と株価の話が毎日3本並ぶと、
　 「自分には関係ない部屋」になって、誰も見に来なくなります。

---

## 4. AIが3本選ぶ ── 選ぶ物差し

残った15〜25本を渡して、**3本だけ**選ばせます。

物差しは、ひとつだけ。

> **「これを読んだ受講生が、今日または今週、自分で何かできるようになるか」**

| ◎ 選ぶ | ✗ 選ばない |
|---|---|
| 新しい機能が使えるようになった | 研究の成果・論文 |
| 無料になった・安くなった | 資金調達・株価・決算 |
| **日本語に対応した** | 海外だけの話 |
| **スマホでできるようになった** | 開発者向けの技術の話 |
| 仕事や暮らしの変わり方 | 企業どうしの提携 |
| 世の中の空気が変わる話（雇用など） | 機能の細かい仕様変更 |

⚠️ **3本そろわない日は、2本でも1本でも構いません。**
　 無理に埋めさせると、関係ない記事が混ざります。
　 **0本の日は、投稿しません。**「今日はありません」も投稿しません（毎日それが続くと、部屋が寂しくなります）。

## 5. どう書くか

### 1本につき、3行だけ

```
① 見出し（20字以内・やさしいことばに直す）
　 → これで、何ができるようになるか（1行）
　 出典URL
```

⚠️ **「で、私に何の関係があるか」の1行が、この機能のすべてです。**
　 これが無いと、ただのニュースの貼り付けになり、読まれません。

### 投稿の形

```
おはようございます。今日のAIニュースです☀️

① ChatGPTが、日本語の音声入力に強くなりました
　 → スマホに向かって話すだけで、長い文章が書けるようになります
　 https://...

② 画像を作るAIが、無料で使える回数を増やしました
　 → お金をかけずに、試せる回数が増えます
　 https://...

③ 大手スーパーが、AIで発注の仕事を自動にしました
　 → 「事務の仕事が減る」という話が、身近なところまで来ています
　 https://...

———
🤖 自動投稿です。気になるものがあれば #質問ひろば でどうぞ🌸
```

### 書き方の決まり（プロンプトに入れる）

- **渡した記事に書いていないことは、一文字も書かない**
- 横文字・専門用語は、かみくだく（「マルチモーダル」→「写真も音も、まとめて扱える」）
- 断定しない。「〜のようです」「〜と発表されました」
- ⚠️ **「稼げる」「儲かる」「必ず」は、絶対に書かない**
- あおらない。「もう乗り遅れます」は書かない
- 1本3行を超えない

## 6. 事故を防ぐ仕掛け

| ⚠️ | 何が起きうるか | 手当て |
|---|---|---|
| **嘘のニュース** | AIが記事を作る | RSSで取れた記事**だけ**を渡す。URLもRSSの実物。AIには作らせない |
| **同じ記事の二度出し** | 毎日似た記事が出る | 出したURLを30日ぶん覚えておく |
| **禁止語** | 「これで稼げます」と書く | 投稿の直前に、**機械で語句チェック**。引っかかったら投稿せずDMで知らせる |
| **RSSが落ちる** | 1媒体が止まる | 8媒体あるので、全滅しない。0本なら**投稿しない** |
| **二重投稿** | 再起動で同じ日に2回出る | 「その日は投稿済み」を記録（朝の投稿と同じ作り） |
| **費用の暴走** | 呼び出しが増える | **1日1回だけ**。`usage.py` に記録され、`!cost` で見えます |

### ⚠️ 最初の2週間は「下書きモード」でお願いします

いきなり自動投稿にしません。

```
Phase 1（2週間）  8:00 に、桜木さんへ**DMで下書き**を送る
　　　　　　　　  👍 を押したら、そのまま #aiニュース へ投稿
　　　　　　　　  何もしなければ、その日は投稿しない

Phase 2          様子を見て、自動投稿に切り替える
```

**認定講師の稼働を待ってから待ち時間を戻す**のと、同じ考え方です。
2週間ぶんの下書きを見れば、選び方が合っているか、言葉がやさしいか、判断できます。

## 7. いつ投稿するか

| | 時刻 | 理由 |
|---|---|---|
| 朝のあいさつ（既存） | 6:30 | — |
| **AIニュース** | **8:00** | あいさつと1時間半あける。朝の家事が一段落する頃 |

⚠️ 6:30の直後に出すと、**2つの投稿が重なって、どちらも読まれません。**

⚠️ 出遅れたときは、**10:00まで**なら出します（朝の投稿と同じ考え方）。
　 昼を回ったら、その日は出しません。「今日のニュース」が夕方に来ると、間が抜けます。

## 8. 費用

| | |
|---|---|
| RSS | **0円**（無料で公開されているもの） |
| AIの呼び出し | **1日1回**。入力2,000〜4,000トークン・出力400トークンほど |
| 1日あたり | **約1円** |
| **1ヶ月** | **約30円** |

いまのAIさくらぎが**月およそ360円**の見込みなので、**1割ほど増える**だけです。

⚠️ ふるいにかけずに200本渡すと、1日10円→月300円になります。**§3のふるいが、費用の鍵**です。
