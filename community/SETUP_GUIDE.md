# Discordサーバー 構築ガイド（setup_discord.py の使い方）
らくらくAIキャンパス コミュニティ／夜想メソッド・21日チャレンジは含めない方針。

このスクリプトは、**チャンネル・ロール・権限を一括で自動作成**します。桜木さんにやっていただくのは「サーバーとBotを作ってトークンを置く」だけです。

---

## 手順（10〜15分）

### 1. サーバーを作る
Discordアプリ左の「＋」→「サーバーを作成」。名前は「らくらくAIキャンパス」等。

### 2. Botアプリを作る（Developer Portal）
1. https://discord.com/developers/applications → **New Application**（名前：らくらくAIサポート 等）
2. 左メニュー **Bot** → **Reset Token** で **トークンをコピー**（＝後で.envに貼る。他人に見せない）
3. 同じBot画面で、下の方の **Privileged Gateway Intents** は今回オフのままでOK

### 3. Botをサーバーに招待する
1. 左メニュー **OAuth2 → URL Generator**
2. SCOPES で **bot** にチェック
3. BOT PERMISSIONS で **Administrator**（管理者）にチェック ← 一番かんたん（構築後に外してもOK）
4. 生成URLをブラウザで開く → 自分のサーバーを選んで **認証**

### 4. サーバーIDを取る
Discordの設定 → 詳細設定 → **開発者モード ON**。
サーバー名を右クリック →「サーバーIDをコピー」。

### 5. .env に2つ記入
`community/.env`（このガイドと同じ階層）に：
```
DISCORD_BOT_TOKEN=（手順2でコピーしたトークン）
DISCORD_GUILD_ID=（手順4でコピーしたサーバーID）
```
※`.env`はGit管理に載せない（トークンは秘密）。

### 6. 実行
```powershell
$py = 'C:\Users\yanagi\AppData\Local\Programs\Python\Python312\python.exe'
& $py -m pip install discord.py python-dotenv
& $py community\setup_discord.py            # 開始セット（推奨）
# & $py community\setup_discord.py --full   # 拡張チャンネルも全部
```
→ ロール・カテゴリ・チャンネルが自動で作られます。**何度実行しても重複しません**（既存はスキップ）。

## 作られるもの（開始セット）
- **ロール**：運営／認定講師／✨マスター・🌟先輩・🌸実践者・🌱はじめの一歩／受講生／興味タグ5種
- **チャンネル**：
  - 🌸はじめに：ようこそ・自己紹介・お知らせ
  - ☀️毎日の習慣：おはようチャレンジ・感謝ノート・できた報告
  - 🖼作品・シェア：ビジョンボード・AI作品ギャラリー
  - 💬学びとサポート：質問ひろば
  - 🌙世界観：雑談-お茶の間
  - 🎤イベント：グループ相談会（ボイス）
- `--full` で追加：オラクルカード／副業チャレンジ／講座のはなし／もくもく会（ボイス）／新月-満月

## 権限の考え方
- **非受講生（@everyone）は全チャンネル非表示**（有料メンバー限定）
- **受講生ロール**を持つ人だけ閲覧・投稿できる
  → 入会者に「受講生」ロールを付ける運用（手動 or 後述のUTAGE連携botで自動付与）
- ようこそ・お知らせは**閲覧のみ**（運営/講師だけ投稿）

## つまずいたら
- 「✗権限不足」と出る → Botに管理者権限が付いていない（手順3をやり直し）
- 「ギルドが見つかりません」→ サーバーID間違い or Bot未招待
- ロール名の絵文字が文字化け → PowerShellの文字コード。無視してOK（Discord上は正しく表示）
