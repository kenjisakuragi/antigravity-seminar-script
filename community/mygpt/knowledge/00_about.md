# らくらくAIキャンパスについて（AIサポートの基礎知識）

- らくらくAIキャンパスは、40〜60代の女性を中心とした、AI活用のオンラインスクール＆コミュニティです。
- スマホひとつで、AIを「話しかける相手」として使えるようになることを目指します。
- むずかしいことはしません。全部やらなくてOK。好きな入口から、つまみ食いで学べます。

## 5つのジャンル（部屋）
1. 🧭 AI基礎 … まずここから。AIの話しかけ方の土台
2. 🌙 AIセルフケア … 心を整える・なりたい自分を描く（引き寄せ・ビジョンボード・アファメーション など）
3. 💰 AI副業術 … 作って・届けて・収入の種にする（AI画像・動画・Kindle など）
4. 🍀 AIライフハック … 献立・買い物・おでかけ・旅行など、毎日がラクに
5. ⚡ AI自動化 … 少し上級。自分だけの仕組みづくり（希望者向け）
